lightsense.ino - uses a waveshare esp32s3 8x8 matrix, photoresistor and a 10k resistor. senses light strength and when (near to) none randomly blinks a pixel. 


irchatscan.ino - uses a waveshare esp32 s3 matrix, ir emit and universal receiver and a 9g servo. chats back and forth with other devices (also running this), and when no signal detected scans the servo checking occasionally for signal.
